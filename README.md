# CodeConnect

Projeto front-end de uma página para cadastrar e publicar projetos, com envio de imagem e gerenciamento de tags.

## Tecnologias

- HTML5 para a estrutura da página.
- CSS3 para os estilos e o layout.
- JavaScript para as interações, como carregar imagem, adicionar/remover tags e publicar o formulário.
- Google Fonts (fonte Prompt).

O projeto não usa frameworks, dependências npm ou etapa de build.

## Como rodar

1. Abra a pasta `code-connect` no VS Code.
2. Abra o arquivo `index.html` diretamente no navegador; ou use a extensão **Live Server** no VS Code e escolha **Open with Live Server**.

Com Live Server, salve as alterações e a página será atualizada automaticamente no navegador.

## Arquivos principais

- `index.html`: estrutura do formulário e navegação.
- `styles.css`: estilos da página.
- `scripts.js`: interações do formulário.
- `img/`: imagens e ícones usados pela interface.

> A publicação e a validação de tags são simuladas no navegador; este projeto não está conectado a um servidor ou banco de dados.
